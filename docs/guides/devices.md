# 设备创建与配置导入

请选择设备的 `*.thingstalk.json` 面板配置。带有 `configuration`、`valid`/`invalid`、`hex`/`reason` 的文件通常是协议测试向量，不能作为面板导入；请改选其 `configuration` 指向的配置文件。

设备列表和发现页提供两种独立入口：

- **手动创建设备**：选择 BLE、MQTT 或双连接，填写名称后创建空白设备；无需导入文件。Web 仅支持 MQTT。
- **从配置文件创建设备**：先校验 JSON，按解析后的 transport 确定类型，预填 title，展示组件和设置表单数量，确认后一次性保存设备与面板。DUAL 一侧没有绑定时仍保持双连接。

扫描选中外设后可从 BLE/DUAL 配置创建并关联；纯 MQTT 配置从设备列表入口创建。导入不自动连接、发送命令或生成 Broker 凭据。写入失败不会留下空设备。

已有设备的“协议与面板”编辑器导入会替换整份草稿，保存后应用；类型必须匹配当前设备。类型不符时使用自动创建入口，或先明确升级设备为双连接。不会猜测并改写已有设备类型。

文件使用 UTF-8 JSON，建议 `.thingstalk.json` 后缀。读取限制 512KiB，解析限制 128K 字符；Android 不依赖文件供应商正确填写 MIME。选择文件返回时等待本机草稿加载，遇恢复冲突或读取错误需先处理。结果通过文件操作区及全局提示显示。

BLE 关联是本机的平台标识，不随面板配置导出。Android 保存地址、iOS 保存系统 peripheral UUID；可尝试直接恢复连接，找不到时再扫描。地址或 UUID 不是跨平台稳定硬件身份，不能只凭名称或服务 UUID 认定同一台设备。

## Web 导入双连接配置

Web 可导入含 MQTT 绑定的 BLE + MQTT 配置。创建确认页会提示“网页版仅支持 MQTT，部分功能可能不可用”，列出保留组件数、跳过组件数和蓝牙设置表单数。编辑器导入和模板导入采用相同规则。

导入生成 MQTT v4 副本：保留 MQTT 发布/订阅、对应能力及数据格式；状态卡需要订阅绑定，交互组件需要发布绑定。BLE 特征读写、通知与设置表单不会带入。原文件不会改写，Web 保存及导出的配置仅含 MQTT。纯 BLE 或没有 MQTT 绑定的双连接文件不能在 Web 导入。Android/iOS 继续使用完整配置。
