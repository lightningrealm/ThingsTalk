# 语言与外观设置

在“我的 → 应用设置”中选择“跟随系统 / 简体中文 / English”。三端共用中英文文案，设置保存在本机，重开后保留。中文系统语言使用简体中文，其他语言回退英文；手动选择优先于系统。旧版外观设置自动使用“跟随系统”，保留原有主题。

应用内切换语言只更新显示，不重建连接会话、导航或表单草稿。Android 响应系统配置变化，iOS 回到前台时重新检查系统首选语言，Web 监听浏览器语言变化并更新网页语言和标题。原生权限弹窗与文件选择器由操作系统控制，其语言遵循系统/系统应用语言设置；应用内选择不会修改系统语言。

设备名、导入面板标题与字段、用户输入、Topic、UUID、原始报文保持原文。内置诊断和历史事件的已知文案在显示时翻译，不改写存档；未知系统或第三方错误原样显示。时间保留明确的 UTC 标记，协议数值与序列化不受显示语言影响。

支持跟随系统、浅色和深色模式，以及五套预设主题色。本机保存，不进入面板配置；保存失败保留当前外观并显示错误。缺失、损坏或未知配置回退默认设置。

页面大面积背景保持中性：浅色 `#F6F7F3`、深色 `#151719`。卡片、边框、标签和控件使用柔和主题色，强调按钮和选中态保持清晰。切换模式或主题使用 280ms 颜色过渡，不重建连接会话。

Android 适配透明系统栏，iOS 同步界面明暗风格，Web 同步外围背景和 color-scheme。系统栏图标按目标明暗模式切换，不逐帧重复设置。当前不支持任意 HEX 取色、动态壁纸色或液态玻璃材质。

应用展示名称随语言显示为“语物”或“ThingsTalk”。Android/iOS 桌面名称遵循系统语言，应用内顶栏与 Web 标题遵循应用语言设置。包名、Bundle ID 和 `.thingstalk.json` 扩展名保持不变。
