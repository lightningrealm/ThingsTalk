# 消息、模板与本地工作台

消息分设备事件和通信记录，支持设备/传输/关键词筛选、未读与待处理、详情和来源设备跳转。连接、错误及设置保存结果生成事件；普通 BLE notify/MQTT 数据只进入通信记录。

打开事件详情自动标已读。已读和已处理独立；后续同类事件不把旧记录改回未读。30 秒降噪聚合仅作用于未读且未确认的同级别事件，并非硬件事件 exactly-once 保证。已读操作返回实际提交数量，批量结果通过避开导航栏和安全区的 Snackbar 显示。

事件最多 1000 条，默认保留 30 天，可选 7/30/90 天。通信记录只保留本次运行最近 500 条；原始负载默认关闭、开启后仅存内存，设备设置特征始终脱敏。原调试台日志有独立清理入口。

事件摘要与模板使用有界 JSON 档案，250ms 合并保存到 Android SharedPreferences、iOS NSUserDefaults、Web localStorage。失败会显示错误并可重试，损坏档案不覆盖。突发进程终止可能丢失尚未落盘的更改；不是可靠告警事务数据库。

模板支持从设备保存、文件导入/导出、校验及载入兼容设备草稿，最多 20 项，单项输入 50,000 字符。应用前确认覆盖草稿，保存后生效；不保存运行时输入与连接库凭据。Web 仅支持 MQTT 模板。

我的页面提供连接管理、MQTT 配置、模板、消息偏好、数据管理、外观、开发者设置及帮助。当前没有云账号、离线事件补收、系统通知或阈值规则引擎。
