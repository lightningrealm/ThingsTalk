# MQTT 连接配置

连接参数从一级页收进二级配置页，工作台和自定义设备共享配置库，各自记住选用项。BLE 关联不受影响，双连接设备只把 MQTT 部分关联到此配置。

## 使用方式

1. 在 MQTT 工作台或设备连接卡片点击“管理连接配置”。
2. 新增配置：填写名称、完整 WS/WSS 地址（含端口、路径）、可选用户名和密码。
3. 默认每次连接生成独立 Client ID；服务器要求固定 ID 时关闭自动生成并填写。同一个固定 ID 的并发连接可能互相踢下线。
4. 顶栏“保存并选用”后返回一级页，直接选择配置并点击连接。

支持编辑、删除和还原未保存修改。离开编辑页丢弃未保存修改。删除配置清除所有引用它的选择记录，不删除设备或面板。修改、删除、切换选用项不会替换已经建立的连接；需要手动断开再连接，新参数才生效。

## 分层与存储

- `domain/mqtt`：`MqttProfile`、配置归档及 `MqttProfileRepository`，用 StateFlow 提供配置状态。
- `data/mqtt`：校验、串行保存与平台存储。先成功持久化再发布状态；读取失败阻止覆盖原数据。
- `presentation/mqtt`：共享配置 ViewModel、选择器、列表和编辑页。凭据原样传给既有连接接口，不拼进 URL、诊断文本或面板导出。
- Android：AndroidKeyStore AES-256-GCM 密钥，独立随机 IV，密文原子写入 noBackupFilesDir。
- iOS：Keychain generic password，AfterFirstUnlockThisDeviceOnly；Keychain 数据可能在卸载后保留。
- Web：localStorage 只保存普通配置及“需要密码”标记；仓库和浏览器存储边界均过滤密码。刷新后需补充密码，不能静默降为匿名认证。

旧设备保存的服务器地址可预填新配置，但旧会话密码没有持久化，因此需重新填写。配置不包含在可分享的面板协议文件内。

## 当前范围

仍使用 MQTT 5 + WS/WSS、干净会话。支持匿名及用户名/密码认证；不支持原生 TCP/TLS、MQTT 3.1.1、URL 凭据/查询参数、自定义 CA 或客户端证书、遗嘱和会话过期配置。QoS/Retain 继续属于消息与面板绑定设置。没有新增自动连接、命令重发、后台保活或系统推送。
