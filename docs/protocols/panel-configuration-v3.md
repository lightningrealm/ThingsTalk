# ThingsTalk 面板与报文配置 v3

配置文件使用 UTF-8 JSON，建议文件名以 `.thingstalk.json` 结尾。文件声明展示组件、能力、收发报文字段及 BLE 服务 / 特征绑定。应用依照声明编解码，不执行配置中的代码或脚本。

入口：设备展示页 → 开发者设置 → 协议与面板编辑；也可以从「我的 → 开发者设置」选择设备。展示页使用已保存的面板；编辑、文本导入和文件导入只改变草稿，点击「保存并应用面板」才替换当前配置。保存不会发送控制命令；已连接时会重新读取、订阅配置的特征。

## 组成

| 字段 | 作用 |
| --- | --- |
| `schemaVersion` | v3 使用 `3`；仍接受 v1 / v2 的旧配置 |
| `title` | 展示页标题 |
| `payloadFormats` | 可复用的收发报文定义 |
| `capabilities` | 组件所呈现的数值、布尔或动作能力，以及范围与单位 |
| `bindings` | 能力的 read / write / notify 分别关联服务、特征及报文字段 |
| `widgets` | 状态卡、开关、滑块、按钮和数值输入的展示顺序与能力引用 |

具体外设关联保存在用户设备中，不写入便携面板文件。相同 UUID 可以在不同设备出现，实际执行始终使用当前设备的连接。导入不创建蓝牙连接，也不更换关联外设。重连后重新根据发现的服务和特征核验属性；无法唯一定位的 UUID 路径会拒绝执行。

## 先定义报文，再绑定组件

`PayloadFormat` 包含唯一 `id`、名称 `label`、编码 `encoding` 和有序 `fields`。首版每种格式最多 32 个字段，每个面板最多 32 种格式；BLE 报文最多 512 字节，写入还受当前连接的实际单包上限限制。

### 定长二进制 BINARY

字节排列为 `prefixHex + 字段 1 + 字段 2 + … + suffixHex`。字段紧密排列，不隐式插入填充字节。读取和通知会校验完整帧长、帧头、帧尾，以及每个字段的合法性。

字段支持 `UINT8`、`INT8`、`UINT16`、`INT16`、`UINT32`、`INT32`、`FLOAT32`、`BOOLEAN`。多字节数字可以选择大小端；显示值为 `raw × scale + bias`，写入使用逆向换算。整数不能精确表达、溢出、无效浮点或未知布尔码会报错，不会偷偷截断。

布尔字段使用 `falseHex` 和 `trueHex`，默认为 `00` / `01`，可以配置为等长的多个字节。字段的 `defaultValue` 是写入时使用的工程值字符串，例如 `"2"`、`"12.5"` 或 `"true"`，不是 HEX。

### 扁平 JSON

`encoding: "JSON"` 时，字段 ID 对应顶层 JSON 键，值为 JSON 数值或布尔值。例如 `{"temperature":23.5,"power":true}`。字段类型为 `FLOAT32` 时可传小数；整数类型仍约束整数范围。JSON 数字直接表示工程值，不使用二进制偏移、大小端、倍率、帧头尾或自定义真假字节，这些参数需为默认值。

接收要求字段集合与声明一致，拒绝缺失、额外或重复键、字符串冒充数字、null、嵌套对象和非法 UTF-8。首版尚未提供字符串、数组、嵌套路径及自由表达式。

### 特征绑定

```json
{
  "serviceUuid": "0000fff0-0000-1000-8000-00805f9b34fb",
  "characteristicUuid": "0000fff1-0000-1000-8000-00805f9b34fb",
  "payload": { "formatId": "status", "fieldId": "temperature" }
}
```

`read`、`write`、`notify` 独立配置，允许不同特征和不同收发格式。读取 / 通知解码整帧后，取所引用字段更新组件；多个组件可以引用同一报文中的不同字段。写入把组件输入放到引用字段，其余字段必须提供显式默认值。不会自动拿最近接收的值拼接控制命令。

按钮对应 ACTION 能力时，可只引用 `formatId`，让每个字段使用默认值生成完整命令，此时不要设置 `fieldId` 或旧的 `actionValue`。旧配置的固定 HEX 动作依然可用。

启用 `payload` 引用时，绑定内旧的 `codec`、偏移、倍率等格式参数必须保留默认值或省略；字节格式只由 `payloadFormats` 决定，写入模式仍单独配置。开发者设置会处理这种切换并在保存前校验。

## 可导入示例

[temperature-power.thingstalk.json](../examples/temperature-power.thingstalk.json) 包含温度卡片和电源开关：

- 状态特征读回或通知 `AA C4 09 01 55`：小端 `INT16` 为 2500，乘以 0.01 后显示 25 ℃，电源为开启。
- 收到 `AA 2E FB 00 55`：显示 −12.34 ℃，电源为关闭。
- 操作电源开关开启：生成 `A1 02 01 EE`；关闭：生成 `A1 02 00 EE`。其中 `02` 是命令字段的默认值。
- 写入完成不等于设备业务执行成功，展示状态依读取回值或通知更新。

示例 UUID 和字节协议仅用于说明格式，需要按实际外设固件调整，不能直接用于未知设备。

## 文件与兼容性

Android / iOS 使用系统文件选择器导入、导出 JSON，不需要额外存储权限。导入文件上限 512 KiB，配置解析另有 128K 字符上限；非法版本、引用或字段会显示错误，不覆盖现有面板。导出的是校验通过的当前草稿，便于在保存前分享与检查。

v1 / v2 仍使用原来的单字段编解码语义。v1 进入编辑器时按既有规则升级为 v2 草稿；添加命名格式后升级为 v3。v3 再次编辑和重启不会降级。旧版本应用无法读取 v3 文件，导出不会自动降级。

Web 当前仅开放 MQTT 工作台，尚未开放此 BLE 面板入口。此轮未增加 MQTT 面板绑定、后台监测、描述符读写、校验和计算、分包组包、任意协议自动识别或脚本执行。
